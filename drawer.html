Character Hierarchy

Drag a character in from the list on the right to add it. Drag a node onto another to nest it, onto empty chart space to make it a root, or anywhere off the chart to take it out — right-clicking does the same. Click a node to set what it passes down.
What gets inherited
Subtracts this much from the insertion order of every inherited entry, once per level of distance, so that nearer ancestors win a budget squeeze. Changing it also changes entry hashes, which resets sticky/cooldown timers once.
Informational card text
Turns an ancestor card's own description into a world info entry, so a purely informational card can carry lore without a lorebook. Switch it on per card by clicking it in the chart above.
